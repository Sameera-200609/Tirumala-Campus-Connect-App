# Tirumala Campus Connect App

A student-focused campus management website for Tirumala Engineering College.

## Project idea
The project brings common campus services into one simple web application. It is designed around the campus situation where students may not be able to use phones freely during college hours, so important information can be accessed through a centralized web interface when permitted.

## Main modules
- Student login
- Student dashboard
- Smart timetable
- Attendance tracking
- Events and announcements
- Lost & Found
- Placement opportunities
- Bus tracking interface
- Faculty appointment request
- Digital Student ID
- Campus AI Assistant (demo FAQ chatbot)

## Technologies used
- HTML5
- CSS3
- JavaScript

## How to run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with Live Server, or open it directly in a browser.
4. Use the Login page to enter any demo Student ID and password.
